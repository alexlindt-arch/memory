# Memory

Memory-Game — Settings-Screen (Theme **DA Projects**), umgesetzt aus dem Figma-/Claude-Design als eigenständige, lauffähige `index.html` (kein Framework, Inline-CSS/JS).

## Features

- Pixelgetreuer Nachbau des Figma-Designs (1440 × 1024, skaliert responsiv herunter).
- Interaktive Auswahl:
  - **Choose player** – Blue / Orange
  - **Board size** – 16 / 24 / 36 Karten
- **Start**-Button wird erst aktiv (gelb), wenn Spieler **und** Boardgröße gewählt sind – inkl. Hover-Effekt (Scale + Icon-Rotation) und Link zum passenden Spielbrett.
- **Game themes**-Navigation (Code vibes / Gaming / DA Projects / Foods).

## Lokal öffnen

`index.html` einfach im Browser öffnen.

## Fonts

Almarai, Red Rose, Orbitron (via Google Fonts).
